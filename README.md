# SleepOutside Personal — Weeks 01–04

A **new, separate** WDD330 practice app. Source product records and tent assets were provided in the original SleepOutside ZIP. The original team project is untouched.

## How to run

1. Extract all files into your empty `sleepoutside` folder. Make sure `package.json` is at the root (not nested one extra level).
2. In VS Code Terminal: `npm install`
3. Start: `npm run dev`
4. Open the URL printed by Vite (normally http://localhost:5173/).
5. Check production build: `npm run build`; preview with `npm run preview`.

## Features

Week 01: responsive storefront; Week 02: JSON-loaded dynamic product list, category/search/sort filters; Week 03: detail pages, quantity, localStorage cart; Week 04: checkout form built-in validation, structured error parsing, demo success page, cleared cart.

**Important:** Checkout is a simulated local exercise, not a real order endpoint. Do not enter real payment card numbers or sensitive data. All prices display in the source data's USD amounts. Tent photos are stored locally from the original ZIP; backpack and sleeping bag photos use URLs provided in its product JSON and may require internet.
